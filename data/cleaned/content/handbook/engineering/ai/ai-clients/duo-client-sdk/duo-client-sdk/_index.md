## 💻 Scope

The Duo Client SDK team is responsible for:

1. **GitLab Language Server (gitlab-lsp)**
   - [Repo](https://gitlab.com/gitlab-org/editor-extensions/gitlab-lsp)
   - [Backlog](https://gitlab.com/groups/gitlab-org/-/issues/?label_name%5B%5D=Editor%20Extensions%3A%3ALanguage%20Server)
   - Slack Channel: [#f_duo-client-sdk](https://gitlab.enterprise.slack.com/archives/C05B1PFHRPU)

The language server provides the shared AI capabilities layer used by all editor extensions, including:

- Code Suggestions (completions and generation)
- Duo Chat integration in editors
- Shared context and configuration management
- IDE-agnostic AI feature delivery
