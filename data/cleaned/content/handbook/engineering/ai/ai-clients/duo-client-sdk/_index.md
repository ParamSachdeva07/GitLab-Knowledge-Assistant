## 🚀 Vision

The Duo Client SDK group builds and maintains the shared infrastructure that enables AI capabilities across all GitLab client surfaces. By providing a robust, well-tested SDK aka language server, we enable other teams to deliver consistent AI experiences regardless of the editor or client.

This group is part of the [AI Clients stage](/handbook/engineering/ai/ai-clients/).

## 💻 Scope

The Duo Client SDK group is responsible for:

1. **GitLab Language Server (gitlab-lsp)**
   - [Repo](https://gitlab.com/gitlab-org/editor-extensions/gitlab-lsp)
   - [Backlog](https://gitlab.com/groups/gitlab-org/-/issues/?label_name%5B%5D=Editor%20Extensions%3A%3ALanguage%20Server)
   - Slack Channel: [#f_duo-client-sdk](https://gitlab.enterprise.slack.com/archives/C05B1PFHRPU)

The language server is co-used by all editor extensions and provides the shared AI capabilities layer.
