## 💻 Scope

The Chat Engine team is responsible for the core engine that powers Duo Chat across all surfaces:

- AI backend and LLM integration for Duo Chat
- Tool integrations and slash commands
- Chat platform capabilities and APIs used by all host systems
- Technical strategy for reliability, scalability, and observability

For the full technical strategy, see the [Duo Chat Technical Strategy](/handbook/engineering/ai/duo-chat/technical-strategy/).
