The CorpSec Devices team owns the security of team member endpoints and the
security tools and controls that run on them.

## Ownership Boundary

CorpSec Devices owns the endpoint security control plane, including:

1. Mobile device management (MDM) architecture, configuration, enrollment, and security baselines
1. Endpoint detection and response (EDR) configuration and deployment
1. Browser security policy and browser extension governance
1. Operating system and third-party software update policy
1. Endpoint security telemetry, compliance monitoring, and automated remediation
1. Device-trust and endpoint application-control enforcement
1. Guarded integrations that perform device actions such as lock, wipe, or restart

[Corporate IT / End User Services](/handbook/eta/corporate-it/end-user-services/)
owns the user-facing support experience, laptop procurement and logistics,
hardware repairs, and delegated routine device actions. Corporate IT and
CorpSec Devices share ownership of end-user endpoint documentation so that
support instructions and security requirements remain aligned.

For team procedures, current tooling, runbooks, and escalation guidance, see
the [CorpSec Devices TeamDocs](https://corpsecdevices.gitlab.net/).
